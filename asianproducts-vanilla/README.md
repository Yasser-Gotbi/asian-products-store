# AsianProducts — نسخة HTML / CSS / JavaScript خالصة

متجر إلكتروني + لوحة تحكم لإدارة المنتجات، بدون أي إطار عمل (framework) وبدون أي خادم خلفي (backend).
الطلبات تُرسل مباشرة إلى واتساب، والمنتجات تُدار من لوحة تحكم بسيطة وتُخزَّن في `localStorage` بالمتصفح.

## هيكل الملفات

```
index.html         الواجهة الأمامية للمتجر (يفتحها الزبون)
admin.html          لوحة التحكم (تضيف وتعدّل المنتجات فقط)
style.css           تصميم المتجر
admin-style.css     تصميم لوحة التحكم
script.js           منطق السلة، الفلترة، وإرسال الطلب عبر واتساب
admin.js            منطق إضافة/تعديل/حذف المنتجات
assets/products/    صور المنتجات
```

## ⚠️ التشغيل — مهم جدًا

لا تفتح الملفات بالنقر المزدوج مباشرة إن أمكن. المتجر ولوحة التحكم يتشاركان بيانات
المنتجات عبر `localStorage`، وبعض المتصفحات (خصوصًا Safari) تتعامل مع التخزين المحلي
بشكل مختلف عند فتح الملفات مباشرة (`file://`) مقارنة بفتحها عبر خادم محلي بسيط.

**الطريقة الموصى بها:**

إن كان لديك Python مثبتًا (الأغلب متوفر افتراضيًا على Mac/Linux):

```bash
cd اسم-المجلد
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/index.html` للمتجر، و
`http://localhost:8000/admin.html` للوحة التحكم.

أو استخدم إضافة "Live Server" في VS Code، أو أي استضافة ثابتة (Static Hosting) مثل
Netlify أو GitHub Pages عند النشر الفعلي — كلها تعمل مباشرة بدون أي إعداد إضافي لأن
المشروع بأكمله HTML/CSS/JS خالص.

## ⚠️ أشياء يجب ضبطها قبل الإطلاق

### 1. أرقام الواتساب (مهم جدًا)

في أعلى ملف `script.js`:

```js
const WHATSAPP_NUMBERS = {
  primary: "213500000000",   // TODO: الرقم الأول
  secondary: "213500000001", // TODO: الرقم الثاني
};
```

استبدل الرقمين بأرقامك الحقيقية بصيغة دولية بدون "+" وبدون صفر البداية.
مثال: رقم جزائري `0555 12 34 56` يصبح `213555123456`.

عند الضغط على "تأكيد الطلب عبر الواتساب"، يظهر للزبون مربع حوار يختار منه أحد
الرقمين، ثم يُفتح واتساب مع رسالة جاهزة تحتوي على تفاصيل الطلب كاملة (لا يتم تخزين
أي طلب في أي مكان — فقط تحويل مباشر إلى واتساب كما طلبت).

### 2. معلومات التواصل في تذييل الصفحة

في `index.html`، ابحث عن `footer-phone` و `footer-email` وعدّل القيم الافتراضية،
وكذلك روابط انستغرام/فيسبوك/تيك توك (حاليًا `#` كعنصر نائب).

### 3. الأسعار والمنتجات

**لا تحتاج لتعديل أي كود لإضافة أو تعديل منتج بعد الآن** — هذا بالضبط ما تفعله لوحة
التحكم. المنتجات الابتدائية الثمانية المدرجة حاليًا هي بيانات تجريبية (Seed) بأسعار
افتراضية؛ عدّلها من `admin.html` مباشرة (زر ✏️ في كل صف)، أو احذفها وابدأ من الصفر.

### 4. رسوم التوصيل

```js
// أعلى ملف script.js
const DELIVERY_FEE = 500; // د.ج
```

قسم "الإعدادات" في لوحة التحكم يعرض هذا الرقم للتوضيح فقط؛ التعديل الفعلي يكون من
هذا السطر في `script.js` (لأن الملفين لا يتشاركان كودًا مباشرة، فقط بيانات المنتجات
عبر `localStorage`).

## كيف تعمل لوحة التحكم

- **إضافة منتج**: زر "+ إضافة منتج جديد" يفتح لوحة جانبية بها: رفع صور (سحب وإفلات
  أو نقر)، الاسم، الفئة، رمز SKU، السعر، بلد المنشأ، الوصف، المكونات (Enter لإضافة
  كل مكوّن)، مواصفات (خاصية/قيمة قابلة للتكرار)، ومفتاح "متوفر للبيع".
- **تعديل منتج**: زر ✏️ في الجدول يفتح نفس اللوحة معبأة ببيانات المنتج الحالية.
- **حذف منتج**: زر 🗑️ يعرض تأكيدًا قبل الحذف.
- **إخفاء/إظهار سريع**: مفتاح التبديل في عمود "الحالة" يُخفي المنتج عن المتجر فورًا
  دون حذفه.
- أي تغيير يُحفظ في `localStorage` فور الضغط على "حفظ المنتج"، ويظهر في `index.html`
  عند فتحه أو تحديثه (وفوريًا إن كان مفتوحًا في تبويب آخر بنفس المتصفح).

### ⚠️ ملاحظة عن حجم الصور

الصور المرفوعة من لوحة التحكم تُخزَّن كنص Base64 داخل `localStorage`، وهو تخزين
محدود المساحة (عادة 5–10 ميغابايت لكل متصفح). صور كبيرة جدًا أو عدد كبير من المنتجات
بصور عالية الدقة قد يتسبب في فشل الحفظ. يُفضّل ضغط الصور (JPG بجودة معقولة، أقل من
300 كيلوبايت للصورة) قبل رفعها. إذا احتجت لاحقًا تخزينًا أوسع وأكثر ديمومة، فهذا يعني
الانتقال إلى قاعدة بيانات حقيقية وخادم فعلي — أمر ممكن لاحقًا لكنه خارج نطاق هذا
الإصدار الخالي من الخادم.

## الأمان

جميع النصوص القادمة من بيانات المنتجات (بما فيها ما يُدخله المدير من لوحة التحكم)
تُمرَّر عبر دالة `escapeHTML()` قبل إدراجها في الصفحة، لمنع أي هجوم XSS عبر أسماء أو
أوصاف منتجات تحتوي على وسوم HTML.
